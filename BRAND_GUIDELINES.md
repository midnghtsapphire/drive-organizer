# Brand Guidelines

## Product Name

**Drive Organizer**

## Positioning Statement

Drive Organizer helps high-volume Google Drive users convert chaotic file storage into a clean, scalable folder system with safe migration controls.

## Brand Pillars

1. **Clarity:** Every file has a defined home.
2. **Trust:** Dry-run defaults, reporting, and secure credential handling.
3. **Momentum:** Reduce admin drag so users can focus on shipping work.

## Voice & Tone

- Clear, practical, and operator-friendly.
- Confident but not exaggerated.
- Security- and reliability-aware in all user-facing docs.

## Messaging Shortcuts

- “Organize before you migrate.”
- “Preview first. Execute with confidence.”
- “From Drive chaos to operational structure.”

## Visual Direction (for future web UI)

- Dark mode friendly with high contrast accessibility.
- Simple hierarchy-first layouts.
- Emphasize scan insights, migration plan, and duplicates dashboard as primary views.
